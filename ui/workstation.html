What will change in the canon
The bulletin amends a single CodeValue in the KG: reason code L (credit-score declination) has its companion_required flag set to FALSE for catastrophe periods, with a version bump and a citation back to B-2026-Q4-118.
MATCH (cv:CodeValue { code: 'L' })
SET cv.companion_required = false,
cv.bulletin_ref = 'B-2026-Q4-118',
cv.version = cv.version + 1,
cv.effective_from = date('2026-03-01')
Then: REFERENCE.TSPR_REASON_CODE_MAP is rebuilt from the KG and reloaded into Snowflake. The L-companion validation rule now passes for any policy whose reason field is just 'L'.
