THE CORE IDEA

A blocker clears exactly two ways — fix the data (step 4) or change the rule (step 5). Both re-run the same rules-as-data engine and both land in the same audit trail. Changing a rule needs no redeploy — the regulation lives in a table, not in code.

What makes it portable

The medallion (Bronze → Silver → Gold) and every rule query run through one engine seam — query() — so the same app runs on Databricks, DuckDB (free/local) or Snowflake by flipping REGULAI_DB. Regulatory provenance is carried in a Neo4j knowledge graph; rules and reason-code canon are materialised into REFERENCE so a new jurisdiction is new rows, not new code.
