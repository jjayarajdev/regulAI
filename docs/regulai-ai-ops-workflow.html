    Governance is config, not documentation

    Policy is authored once and enforced at runtime by each layer: access matrix → engine seam (query()) · compute thresholds → Databricks metering · eval criteria → anomaly detection · content rules → rules-as-data (REFERENCE.TSPR_VALIDATION_RULES). A new regulatory bulletin flips a rule flag at runtime — no redeploy, no rewrite.

    Two non-negotiables: one enforcement chokepoint that can't be routed around (the query() invocation boundary — every engine reads through it), and one shared audit spine all layers write to (gold_audit) — so every product reconciles to one provable record.
