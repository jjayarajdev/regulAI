# Commissioner's Bulletin # B-2026-Q3-104 (synthetic)

**TO:** All insurers writing residential property insurance in Texas

**RE:** Revisions to the Texas Statistical Plan for Residential Risks — Cause of Loss reporting for named storm events

**Date:** July 1, 2026 (synthetic — for RegulAI POC demonstration only; not an actual TDI bulletin)

---

## §1. Authority and effective date

Pursuant to the Commissioner's authority under Texas Insurance Code §38.001 and §551.001, this bulletin amends the Texas Statistical Plan for Residential Risks (TSP-Res) effective January 1, 2026, with respect to the reporting of Cause of Loss codes for windstorm events.

The amendments described in this bulletin take effect for losses with accident dates **on or after October 1, 2026**.

## §2. Cause of Loss code modifications

Section B, Rule 12 of the Texas Statistical Plan for Residential Risks ("Cause of Loss Codes") is modified as follows:

**Code 25 ("Windstorm")** is narrowed to apply only to wind losses **not** associated with a named storm event. The description for code 25 shall read: "Windstorm — wind losses not associated with a named storm event as designated by the National Weather Service or its successor."

**Code 26 ("Named Storm Wind")** is added to the Cause of Loss code list with the following definition: "Wind losses associated with a named storm event, including hurricanes and named tropical storms designated by the National Weather Service or its successor agency. Includes wind, hail, and water damage caused by wind-driven rain occurring during the named storm event window."

## §3. New required fields

For all loss records reporting Cause of Loss code 26, carriers must report the following additional data elements as part of the Loss Record Layout (Section D):

- **NAMED_STORM_NWS_ID** (alphanumeric, 12 positions): the official National Weather Service identifier for the named storm (e.g., "AL092024" for Hurricane Helene).
- **NAMED_STORM_CATEGORY** (numeric, 1 position): the Saffir-Simpson category of the storm at the time of landfall, or "0" for tropical storms, or "9" if not applicable.
- **NAMED_STORM_LANDFALL_DATE** (numeric, 8 positions, YYYYMMDD format): the date of named storm landfall in Texas, or the closest approach date for storms that did not make landfall.

These fields shall be reported in positions 161–181 of the loss record. Records reporting Cause of Loss code 25 (the narrowed "Windstorm" code) shall report blanks in these positions.

## §4. Effect on other reports

This modification does not change the structure of the Premium Record Layout (Section C), the Cancellation/Nonrenewal/Declination Notice Record Layout (Section E), or the Number of Actual Cancellations, Nonrenewals, and Declinations Record Layout (Section G).

The Transmittal Form (Rule 29) total fields are unchanged.

## §5. Backfill and transition

For losses with accident dates between January 1, 2026 and September 30, 2026 that were originally reported under Cause of Loss code 25 but that meet the definition of code 26 under this bulletin, carriers are **not** required to backfill or restate prior submissions. The new code 26 applies only to losses with accident dates on or after October 1, 2026.

## §6. Reconciliation

The reconciliation requirement in Section A, Rule 35 (counts reconciled against NAIC MCAS) is unaffected.

## §7. Questions

Questions regarding this bulletin should be directed to TICO at PCActuarial@tdi.texas.gov.
